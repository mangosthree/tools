= MaNGOS-Tools -- README =


Contains 2 Tools
====

### EventAI Creator
Allows simplified creation of EventAI scripts


### MaNGOS Patcher
Applies a patch to the game executable which allows it to be used to private servers.
- Make sure you back up your original .exe
